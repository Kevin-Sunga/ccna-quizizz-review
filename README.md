# CCNA Quizizz Review

A static Quizizz-style review app for CCNA Modules 6-8 questions.

## Deploy on Vercel

1. Import this GitHub repository in Vercel.
2. Keep the framework preset as `Other`.
3. Leave the build command empty.
4. Use `.` as the output directory.

The app is plain HTML, CSS, and JavaScript, so it does not need installation or a build step.
