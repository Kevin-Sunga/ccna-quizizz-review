# CCNA Quizizz Review

A static Quizizz-style review app for CCNA 3 (ENSA) Modules 1-12.

Modules 9-12 add original practice questions covering QoS, network management,
campus design, and troubleshooting. References include [Cisco's QoS FAQ](https://www.cisco.com/c/en/us/support/docs/quality-of-service-qos/qos-policing/22833-qos-faq.html),
[SNMP security guide](https://www.cisco.com/c/en/us/support/docs/ip/simple-network-management-protocol-snmp/20370-snmpsecurity-20370.html),
[campus design guide](https://www.cisco.com/c/en/us/td/docs/solutions/Enterprise/Campus/Borderless_Campus_Network_1-0/Borderless_Campus_1-0_Design_Guide/BN_Campus_Models.html),
and IETF specifications for [DSCP](https://www.rfc-editor.org/rfc/rfc2474)
and [NTP](https://www.rfc-editor.org/rfc/rfc5905).

## Deploy on Vercel

1. Import this GitHub repository in Vercel.
2. Keep the framework preset as `Other`.
3. Leave the build command empty.
4. Use `.` as the output directory.

The app is plain HTML, CSS, and JavaScript, so it does not need installation or a build step.
